# lusitania

Landing page mobile-first da Pousada Lusitania com guia digital do hospede.

## Deploy na Vercel

1. Importe este repositório na Vercel.
2. Framework preset: Vite.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Cadastre as mesmas variáveis do arquivo `.env.example` no painel da Vercel.

### Variáveis de ambiente

Use o arquivo `.env.example` como base para configurar:

- `VITE_URL_SITE`
- `VITE_URL_TOUR_360`
- `VITE_URL_ACOMODACOES`
- `VITE_URL_GALERIA`
- `VITE_URL_RESERVAS`
- `VITE_URL_MAPS`
- `VITE_URL_WHATSAPP`
- `VITE_WIFI_REDE`
- `VITE_WIFI_SENHA`
- `VITE_CAFE_DA_MANHA`
- `VITE_HORARIO_SALA_TV`
- `VITE_HORARIO_PISCINA`
- `VITE_HORARIO_SALA_JOGOS`
- `VITE_HORARIO_AREA_PISCINA`
- `VITE_HORARIO_SAUNA`
- `VITE_ARRUMACAO_LIMITE`
- `VITE_CHECKOUT`
- `VITE_CHECKOUT_ESTENDIDO_VALOR`
- `VITE_CHECKOUT_ESTENDIDO_REGRA`
